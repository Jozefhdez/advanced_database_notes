## What I understood
- Transactions group SQL statements so they all succeed or all fail together
- COMMIT saves changes, ROLLBACK undoes them
- SAVEPOINT lets you partially roll back within a transaction
- Stored procedures wrap logic in the DB, handle COMMIT/ROLLBACK internally
- Functions return values and work in SELECT; procedures don't
