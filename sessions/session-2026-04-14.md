## What I understood
An index is an object use to perform faster operations on data retrieval, there are multiple types of indexes such as:
1. Index: uses a B-Tree (balanced tree).
2. Hash index: uses a hash function to map a value to the space in memory its stored.
3. Composite index: an index on multiple columns.
4. Partial index: database index built over a subset of a table, defined by a conditional expression using a WHERE clause.
