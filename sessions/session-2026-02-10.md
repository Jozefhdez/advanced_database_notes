## What I understood
- SELECT column FROM table retrieves specific data.
- SELECT * retrieves all columns.
- WHERE filters rows before returning results.
- BETWEEN includes both boundary values.
- LIKE supports pattern matching using %.
- ORDER BY sorts ascending by default, DESC reverses it.
