## What I understood
- ORM is an abstraction layer that lets you interact with a relational DB using objects instead of raw SQL
- SQLAlchemy implements ORM in Python. It maps Python classes to DB tables and handles connections through an Engine
- A DB migration is a versioned script that modifies the schema. It keeps the DB structure in sync with the codebase.
- Alembic is built on top of SQLAlchemy and manages those migration scripts. Each script has an `upgrade()` and a `downgrade()` function, so you can apply or revert changes.
